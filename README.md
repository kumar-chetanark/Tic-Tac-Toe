# Tic-Tac-Toe

A browser-based two-player Tic-Tac-Toe game built with vanilla JavaScript.

## What it does

- Two players take turns marking a 3x3 grid
- Detects wins across rows, columns, and diagonals
- Detects a draw when the board fills with no winner

## Tech Used

- HTML5
- CSS3
- JavaScript (DOM manipulation, event handling)

## Run it locally

```bash
git clone https://github.com/kumar-chetanark/Tic-Tac-Toe.git
cd Tic-Tac-Toe
```

Then open `index.html` in your browser.
